## 怎么用

1. `npm run dev`，打开终端输出地址（默认 `http://localhost:5173`，被占用顺延）。
2. 从左菜单逐项点，按下面清单勾 `[x]`。
3. **详情页（带 :id）从菜单直点会回退到预置示例**，正常；真实联动按「交互联动」一节走。
4. 发现问题记在每节末尾的「问题」里，回头发我。

## C. 交互 / 跨终端联动重点

> 原型的核心卖点是"一端操作、另一端可见"。这些要按顺序点，别只截图。

### C1 主线 1 急救（患者 ↔ 医生 PC）
- [ ] 患者 `/patient/sos` 点一键 SOS → 跳就近医院 → 选医院 → 等待页状态轴推进
- [ ] 切医生 PC `/doctor/rescue` 工作台 → 看到刚才那条新求救（张建国）
- [ ] 进患者实时视图 → 点「接诊」→ **浏览器后退**回患者等待页 → 出现「王医生 已接诊」

### C2 主线 3 协作（医生 PC → 医生 APP）
- [ ] PC `/doctor/referral/new` 发起转诊 → APP `/doctor-app/inbox` 收件箱出现
- [ ] MDT 邀请 / 共享 同理；APP 端接受/拒绝有反馈

### C3 医患消息（患者 ↔ 医生 APP，共享线程）
- [ ] 患者 `/patient/care/doctor-chat` 发一条消息
- [ ] 医生 APP `/doctor-app/messages` 打开张建国会话 → **能看到刚发的消息** → 回复 → 患者侧可见

### C4 质控质疑闭环（内网 ↔ 医生 PC，v3 重点）
- [ ] 内网 `/intranet/qc` 质控工作台 → 点「发起质疑」→ 列表新增一条 pending
- [ ] 医生 `/doctor/answer` 数据答疑 → 选中该条 → 填写答疑提交
- [ ] 回内网 `/intranet/qc/QT-01`（或菜单质疑工单）→ 状态变「已答疑」→ 点「锁定入库」→ 变「已锁定」

### C5 单页交互
- [ ] P110 用药打卡：点已服/漏服，依从率圆环实时变
- [ ] P111 陪护对话：发几轮后**自动结束**（状态机不回环）
- [ ] P113 随访问卷：滑块/单选/进度条，未答完拦截提交
- [ ] P204 蛇伤判定：点「采纳建议」自动填表
- [ ] P306 脱敏规则：开关切换有反馈
- [ ] P307 映射工作台：待确认项点「确认」变状态
- [ ] P220 培训管理：草稿「发布」/审核中「通过」状态变化
