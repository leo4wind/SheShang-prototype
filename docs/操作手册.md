# 圣蛇蛇伤一体化平台 · 演示手册（业务版）

> 给谁看：业务、管理、设计等非技术同事。
> 看完能干嘛：约 10 分钟看懂这套系统覆盖哪些场景、谁在用、长什么样、怎么用。
> 一句话说明：这是一个**演示样板**，里面的数据都是模拟的，用来直观呈现系统的样子和用法。

---

## 一、这套系统是做什么的

围绕"被毒蛇咬伤"这件事，把 **从呼救、救治、多院协作，到出院后康复随访，再到背后的数据汇聚** 串成一个完整平台。

服务四类人，用在三个地方：

| 谁在用 | 在哪用 | 主要做什么 |
|---|---|---|
| 蛇伤患者 | 手机小程序 | 一键求救、上报现场、查看就诊、康复随访 |
| 接诊医生 | 电脑 + 手机 | 远程指导、判定蛇种、记录救治 |
| 多院专家 | 手机 | 转院、多科会诊、共享患者 |
| 数据 / 科研人员 | 内部系统 | 汇聚与核对数据、统计分析、看板大屏 |

---

## 二、怎么打开

- 技术同事启动后会给你一个**网址**，用电脑浏览器（建议 Chrome）打开即可，不用安装任何东西。
- 打开后：**左边是菜单**（按"谁在用"分成几组），**右边是内容**。
- 患者和医生手机上的页面，会显示成一个**手机外框**的样子；电脑和内部系统的页面铺满整个屏幕。
- 顶部可以切换"当前角色身份"，用不同人的视角来看。

## 三、四条主线（建议按顺序看）

> 下面用"点哪里、看到什么"的方式带你走一遍。括号里的名字就是屏幕菜单上的文字。

### 主线一：蛇伤急救（最有代入感，先看这条）

讲一位患者从求救到被医生接诊的全过程，能看到**患者端和医生端是连通的**。

1. 左菜单：**患者端 → 应急求救 → 求救首页**。点中间红色的"一键 SOS"大按钮，系统自动定位并跳到附近医院。
2. 在医院列表里，有蛇伤救治资质的排在前面（没资质的不能选）。选一家点"选择并前往"，进入"就诊进度"页，能看到状态一步步往前走。
3. （可选）点"上报现场信息"，填症状、拍照、语音。
4. 切到左菜单：**医生端 → 救助 → 救助工作台**。**刚才那位患者的求救，已经出现在医生的接警列表里。**
5. 点开看患者实时情况（现场照片、既往病史、AI 识别出的可能蛇种），点底部"接诊此患者"。
6. 点浏览器左上角的"返回"箭头，回到患者刚才的页面——**会看到"医生已接诊"的提示**。

> 这一步是整套系统最核心的价值：**一端操作，另一端马上看得到。**

### 主线二：多院协作

基层医生处理不了时，转给上级医院、或请专家一起会诊。

1. **医生端 → 多中心分诊 → 转诊申请**：选接收医院、填原因、定紧急程度，提交。
2. 切到 **医生端 APP（手机）→ 收件箱**：**接收方医生能看到这条转诊**，旁边还有会诊邀请、别人共享给他的患者。点开可以接受或拒绝。
3. 同样可以体验"多科会诊"（多个专家一起看同一个病人）和"共享患者"（把病人资料安全地给到另一位医生）。

### 主线三：康复陪护

患者出院后的随访、用药和康复管理。

1. **患者端 → 健康陪护 → 我的随访计划**：出院后自动排好的随访时间表（第 3 天、第 7 天…直到一年）。
2. **用药打卡**：点"已服 / 漏服"，上方的完成率会实时变化。
3. **陪护对话**：和智能助手对话、汇报恢复情况（聊几轮会自动收尾）。
4. 还能看：康复趋势图、打卡日历、随访问卷、健康科普文章。
5. **医患消息**：患者给医生发消息（患者端 → 我的医生），医生在手机上（医生端 APP → 患者消息）能收到并回复——**两边是同一个对话**。

### 主线四：数据底座（支撑前面三条）

所有数据汇集、核对、统计的地方，都在"内网端"。

1. **内网端 → 数据接入**：看各个数据来源的接入情况（哪些是实时的、哪些是批量的）。
2. **数据治理**：数据进来后会做清洗、脱敏（隐藏隐私信息）、整理等处理，可以看到处理前后的对比。
3. **质量控制**：发现可疑数据时，质控人员发起"质疑" → 医生在"数据答疑"里回答 → 质控确认后"锁定"入库。**这是一条跨部门的闭环。**
4. **统计分析、科研表格、患者全景档案**也都在这里。

## 四、几个值得专门看的亮点

- **数据流转大屏**（系统能力 → 数据大屏）：一张大图看清数据从哪来、怎么处理、最后给谁用，配实时指标。
- **各种图表**：康复趋势、统计分析、用药完成情况分布等，直观好看。
- **质控—答疑闭环**（主线四第 3 点）：体现数据是"被认真核对过的"，可信。
- **患者全景档案**：把一位病人散落在急救、就诊、会诊、随访各处的记录，按时间汇成一条清晰的线。

## 五、看的时候请注意

- 标着 **"示例数据"** 的地方，是模拟内容，不是真实病例。
- **黄色高亮的"算法接入点"**：是将来接入 AI（如蛇种识别、智能判定）的位置，现在显示的是模拟结果。
- 直接从菜单点开"某位患者的详情"这类页面，看到的是一份**示例档案**；想看你自己刚操作出来的内容，请按上面主线的步骤一步步点进去。
- **刷新网页**会回到最初状态（你点出来的新内容会清空）。
